# @depose/frontend

Frontend Vite + React SPA yang menggunakan `@depose/ui` sebagai library komponen.

## Pengembangan

Jalankan dev server:

```bash
pnpm dev
```

Jalankan typecheck:

```bash
pnpm check-types
```

## Catatan

- Semua komponen UI diambil dari `@depose/ui`.
- Globals CSS di-import dari `@depose/ui/globals.css`.
- Konfigurasi alias `@/*` menunjuk ke `src/*`.
